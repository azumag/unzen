# Multi-segment artifact verifier hash boundary

`verify_multi_segment_artifacts.py` treats the lower-level `_measure_file(..., chunk_size=...)` and `sha256_file(..., chunk_size=...)` controls as runtime input rather than relying on Python type annotations.

`chunk_size` must be an exact positive Python integer. Booleans are rejected even though `bool` subclasses `int`; zero, negative values, floats (including `NaN` and infinities), strings, `None`, and other non-integers fail before `os.open()` is called. This prevents `read(0)` from returning an empty-payload digest and prevents negative values such as `-1` from turning the intended bounded loop into a whole-file read.

Valid positive chunk sizes, including the default and small values such as one byte, continue to hash the complete raw payload. The verifier first resolves the requested manifest or artifact path to one regular-file identity, opens that resolved file with the available raw/nonblocking/no-follow/close-on-exec flags (`O_BINARY`, `O_NONBLOCK`, `O_NOFOLLOW`, and `O_CLOEXEC` where the platform provides them), and requires the opened descriptor fingerprint to match the pre-open path fingerprint. Hashing and manifest reads then stay on that descriptor.

A successful read is also tied back to the pathname identity. Before accepting the bytes or SHA-256, the verifier requires the descriptor fingerprint to remain unchanged, requires the resolved pathname to still name that same regular file, and requires the originally requested path to still resolve to the same target. Replacing a file after `open()` therefore fails closed even when the replacement contains identical bytes; a stale unlinked descriptor is not sufficient for a passing integrity result. Stable symlink inputs remain supported because the target is resolved before the no-follow descriptor open and the requested symlink is re-resolved before acceptance.

The existing missing graph/external-data diagnostics, split-manifest/report schemas, browser artifact budgets, and production evidence requirements are unchanged. This contract is defense-in-depth for direct and future programmatic callers as well as the normal artifact-integrity gate.
