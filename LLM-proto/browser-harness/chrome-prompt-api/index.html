What this page measures

This harness exercises the LanguageModel Prompt API inside the top-level document execution context (Chrome Built-in AI). Model preparation has its own lifecycle — availability, user activation, first download, language — which the scenarios below record. The report is self-reported: it is NOT "real-browser verified" evidence until an operator wraps it in a captured-and-verified envelope with an artifact loader and an independent verifier (src/evidence.ts / src/chrome-prompt-api-report.ts).

Serve this folder over http://localhost (the Prompt API requires a secure-ish origin) and click Run scenarios. The model download may take a minute on the first run; a user activation from the Run click is required for the first download.
