Browser-delegated function execution with server-side fallback

How it works (Phase 2: 4-Layer Isolation)

  • Browser First: Functions execute in your browser via Web Worker + QuickJS Wasm sandbox
  • 4-Layer Isolation: Web Worker thread → Wasm memory sandbox → QuickJS interpreter → API restrictions
  • Automatic Fallback: If browser execution fails (runtime error), the server handles it
  • Same Security: Server and browser use identical security hardening (frozen prototypes, no eval/Function)
