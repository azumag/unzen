# QJS セキュリティ制約とユースケース

## 1. 外部接続禁止ポリシー

QJS Workerは第三者のブラウザ上で動作するため、セキュリティ上の理由により
外部接続は一切禁止される。

### 1.1 禁止されるAPI

| API | 理由 |
|-----|------|
| fetch / XMLHttpRequest | HTTP/HTTPSリクエスト禁止 |
| WebSocket | リアルタイム外部通信禁止 |
| navigator.sendBeacon | ビーコン送信禁止 |
| WebRTC (DataChannel以外) | P2P通信制限 |
| DNSプリフェッチ | DNS経由の情報漏洩防止 |

### 1.2 許可される処理

- 入力データの変換・整形
- 計算・検証・フィルタリング
- 暗号化・ハッシュ計算
- 正規表現処理

### 1.3 禁止の根拠

外部接続を許可した場合、攻撃者が悪意あるコードを登録し、
Workerブラウザを踏み台として他サイトへの攻撃に利用可能。
これによりプラットフォーム全体のIPレピュテーションが低下し、
法的責任問題が生じる。

## 2. 対象ユースケース（純粋計算処理）

すべての入力データは事前に取得済みである必要がある。
処理対象データはAPIリクエストボディまたはWebhookペイロードとして渡される。

| カテゴリー | 具体例 | 対象外 |
|-----------|--------|--------|
| データ変換 | JSON ↔ XML, CSVパース, Base64変換 | 外部APIからのデータ取得 |
| 検証・フィルタリング | 正規表現マッチ, スキーマ検証, 入力検証 | 外部検証サービス呼び出し |
| 暗号化・ハッシュ | SHA-256計算, JWT署名検証, チェックサム | 外部認証サーバー接続 |
| 数値計算 | 統計処理, 数値シミュレーション | 外部データベース参照 |
| コード変換 | フォーマット変換, Minify, Markdown→HTML | 外部リソースの動的取得 |
| 軽量画像処理 | メタデータ抽出, サイズ計算 | 外部画像URLの直接取得 |

## 3. 対象外のユースケース

以下は外部接続が必要なため、QJSの対象外:

- Webスクレイピング
- 外部API呼び出し
- ウェブクローリング
- リアルタイムデータ収集
