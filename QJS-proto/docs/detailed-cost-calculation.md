## 付録：計算式一覧

### A. Worker報酬計算式
```
報酬 = シャード数 × 単価
     = 8 × $0.0001
     = $0.0008
```

### B. 原価合計式
```
原価 = CF_Workers + Worker報酬 + その他
     = $0.0000015 + $0.0008 + $0.00025
     = $0.0010515
```

### C. 利益率計算式
```
利益 = 販売価格 - 原価
     = $0.00137 - $0.00105
     = $0.00032

利益率 = 利益 ÷ 販売価格 × 100
       = $0.00032 ÷ $0.00137 × 100
       = 23.4%
```

### D. トークン換算式
```
Input:  原価 ÷ 入力トークン数 × 1000
       = $0.00105 ÷ 1000 × 1000
       = $0.00105/1K tokens

Output: 原価 ÷ 出力トークン数 × 1000
       = $0.00105 ÷ 500 × 1000
       = $0.00210/1K tokens
```
