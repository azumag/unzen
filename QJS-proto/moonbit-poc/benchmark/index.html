Benchmark Methodology

  • Each benchmark runs 10 iterations, reporting P50 (median) timing
  • 1 warm-up run is excluded from measurements
  • Timing uses performance.now() (microsecond precision)
  • Native JS uses V8 JIT (Chrome) or SpiderMonkey (Firefox)
  • MoonBit wasm-gc requires browser support (see compatibility below)
  • Algorithms are identical across all runtimes for fair comparison

How to Add MoonBit Wasm

After building MoonBit packages with moon build --target wasm-gc, copy the generated .wasm files to this directory and update benchmark.js to load them. See the README for details.
