# セキュリティ制約とユースケース

## 1. 外部接続禁止ポリシー

unzenで委任される関数はサンドボックス内で実行されるため、外部接続は一切禁止。

### 1.1 なぜ禁止するのか

たとえ自己消費モデルであっても、サイトオーナーが配信する関数コードに
悪意がある可能性を排除できない。外部接続を許可した場合:

- 訪問者ブラウザを踏み台として他サイトへの攻撃に利用可能
- 訪問者の個人情報を外部に送信可能
- プラットフォーム全体のIPレピュテーション低下

外部接続禁止により、これらの攻撃ベクトルを根本的に排除する。

### 1.2 禁止されるAPI

| API | 理由 |
|-----|------|
| fetch / XMLHttpRequest | HTTP/HTTPSリクエスト禁止 |
| WebSocket | リアルタイム外部通信禁止 |
| navigator.sendBeacon | ビーコン送信禁止 |
| WebRTC DataChannel | P2P通信禁止 |
| DNSプリフェッチ | DNS経由の情報漏洩防止 |

### 1.3 許可される処理

- 入力データの変換・整形
- 計算・検証・フィルタリング
- 暗号化・ハッシュ計算
- 正規表現処理

## 2. 対象ユースケース

訪問者自身が必要とする機能を、ブラウザ側で実行する。
入力データはクライアントSDK経由で関数に渡される。

| カテゴリー | 具体例 | なぜブラウザで実行？ |
|-----------|--------|-------------------|
| フォームバリデーション | スキーマ検証、入力チェック | サーバーへの往復不要で即座にフィードバック |
| データ変換 | JSON ↔ XML, CSVパース, Base64 | ローカルデータなのでサーバーに送る必要がない |
| コンテンツフィルタリング | スパム判定、NGワード検出 | プレビュー段階でのリアルタイム判定 |
| 暗号化・ハッシュ | SHA-256計算, チェックサム | ローカル完結、サーバーコスト削減 |
| 数値計算 | 統計処理、スコアリング | レスポンス速度向上 |
| コード変換 | Markdown→HTML, Minify | エディタ内でのリアルタイム変換 |
| 軽量画像処理 | メタデータ抽出、サイズ計算 | アップロード前のクライアント処理 |

## 3. 対象外のユースケース

以下は外部接続が必要、または副作用を伴うためunzenの対象外:

- 外部APIの呼び出し
- データベースへのアクセス
- ファイルシステムの操作
- DOM操作 (Web Worker内では不可)
- タイマー/非同期スケジューリング

## 4. 制限値

| 項目 | 制限 | 理由 |
|------|------|------|
| メモリ | 16MB | モバイル端末への配慮 |
| 実行時間 | 50ms | UIブロック防止 |
| スタック | 256KB | スタックオーバーフロー防止 |
| 入力サイズ | 64KB | メモリ消費の制限 |
