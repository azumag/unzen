unzen core E2E Demo

Run registered functions in your browser sandbox, with automatic server-side fallback.

Demo only. This page is not a production system and makes no production guarantees. Timings and statistics are measured in this session and reset on reload.

How it works

  • Browser first: the manifest and function source are fetched, then the function runs in a QuickJS interpreter over WebAssembly inside a Web Worker — off your page's main thread.
  • Automatic fallback: if the browser attempt fails (e.g. a runtime error), the same function is executed server-side.
  • Cancellation is yours: cancel aborts the run immediately and never triggers a server fallback.

Security boundaries (what this demo actually shows)

The sandbox isolates untrusted function code from your page: it runs in a separate Web Worker thread in a QuickJS interpreter with eval/Function/Proxy removed and built-in prototypes frozen. That protects your page from the function code. It does NOT replace a server-side trust boundary, a Content Security Policy, or authentication.

                  Session statistics

                  Counted in this browser tab only. Values reset on reload or when you press Reset.

                  Definitions
                  Browser success
                  A function finished in the browser sandbox without server fallback.
                  Fallback success
                  The browser attempt failed and the server produced the result.
                  Input error
                  Input was rejected before execution by this demo's validation.
                  Function error
                  The function code threw an error.
                  Runtime error
                  The browser sandbox itself failed to execute (e.g. a Wasm/worker problem).
                  Server error
                  The server-side fallback failed.
                  Network error
                  Could not reach the server (manifest/code fetch or fallback HTTP request).
                  Cancelled
                  The user cancelled the run.
                  Cache hit
                  The manifest was already cached in this session.
                  Unknown
                  Unexpected / unclassified outcome.
                  Avg total time
                  Mean wall-clock time per completed execution. Sample count shown.
                  Avg browser attempt
                  Mean duration of browser attempts. Sample count shown.
                  Avg server attempt
                  Mean duration of server fallback attempts. Sample count shown.
